# 飲食店求人の時給分析プロジェクト

## 仮説
**「チェーン店より個人店の方が、時給範囲は広いのではないか」**

## プロジェクト概要
求人ボックスから東京都の飲食店求人データをスクレイピングし、チェーン店と個人店の時給範囲を比較して仮説を検証します。

## ファイル構成
- `scraper.py`: 求人データのスクレイピングスクリプト
- `analyze.py`: データ分析・可視化スクリプト
- `requirements.txt`: 必要なPythonパッケージ
- `restaurant_jobs_tokyo.csv`: 収集したデータ（実行後に生成）
- `wage_analysis.png`: 分析結果のグラフ（実行後に生成）

## 使い方

### 1. 環境準備
```bash
pip install -r requirements.txt
```

### 2. データ収集
```bash
python scraper.py
```
- 東京都の飲食店求人から時給データを収集
- robots.txt に準拠（2秒間隔でリクエスト）
- デフォルトで10ページ分を収集

### 3. データ分析
```bash
python analyze.py
```
- 統計分析（平均、中央値、標準偏差など）
- t検定による有意差検定
- グラフの生成と保存

## データ項目
- **company_name**: 企業名
- **title**: 求人タイトル
- **pay_text**: 給与テキスト
- **hourly_wage_min**: 最低時給（円）
- **hourly_wage_max**: 最高時給（円）
- **employment_type**: 雇用形態
- **store_type**: 店舗タイプ（チェーン店/個人店/不明）
- **wage_range**: 時給範囲（最高 - 最低）

## 分類ロジック

### チェーン店の判定
以下のキーワードが企業名に含まれる場合:
- 株式会社、有限会社、合同会社
- チェーン、グループ、ホールディングス
- Inc、Co.,Ltd、Corporation

### 個人店の判定
- 上記キーワードがない
- 企業名が短い（10文字以下）
- 「個人」「オーナー」「自営」「家族経営」などのキーワード

## 注意事項
- スクレイピングは robots.txt に準拠しています
- 大量のデータ収集は控え、必要最小限に留めてください
- User-Agent を適切に設定しています
- リクエスト間隔は2秒に設定されています
